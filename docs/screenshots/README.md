# Screenshot Capture Points

The project keeps screenshot capture points documented without checking binary
artifacts into source control. Release documentation should capture these
terminal states using a real device or the deterministic test fixtures:

- `home-dashboard.png` — physical storage inventory and selection.
- `benchmark-progress.png` — active disk, workload, progress, throughput and ETA.
- `results-dashboard.png` — completed workloads, score and charts.
- `history-comparison.png` — filters, metric deltas and trend chart.
- `settings-dialog.png` — persistent benchmark settings.

Screenshots must redact serial numbers, mount paths and any other sensitive
machine-specific information before publication.
